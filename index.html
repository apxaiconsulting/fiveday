Planning

Every date in Fiveday — what counts as today, what "by Friday" resolves to, and which day a completed task lands on in the EOD report — is read in the working timezone, not the clock on this device.

AI reading

With this on, pasted text is read by Gemini through the same Cloudflare Worker your other apps use, which keeps the API key off this page. If the call fails or times out, Fiveday falls back to the built-in rules and tells you. The worker only accepts requests from apxaiconsulting.github.io, so AI reading is unavailable when you open the app from a local file or localhost.
